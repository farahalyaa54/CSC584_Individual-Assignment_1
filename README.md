PERSONAL PROFILE WEB APPLICATION

Project Description: 
This project are developed for CSC584 Individual Assignment 1. This web application allowed users to enter their student personal information and diplays the submitted information of them on a profile page.


Technologies been used:
- HTML (HyperText Markup Language)
- JSP
- Java Servlet
- CSS (Cascading Style Sheet)
- NetBeans IDE 8.2
- JDK 8
- GlassFish Server 4.1.1
  
Features in the application:
- Students can enter their personal information which is Full name, Student Id, Programme, Email, Hobbies, and a Short Self-Introduction
- After then, students will be shows their information pages.
- Students also can navigate back to the personal information form.
  
Project Structure:
- index.html (Personal information form).
- ProfileServlet.java (To process the submitted data information of students).
- profile.jsp (To display the submitted form of students).
- style.css (To make web interface more interactive).
  
How to Run the Application:
- Install the JDK 8 and NetBeans IDE 8.2.
- Configure the GlassFish Server 4.1.1 in Netbeans when installing.
- Open the project in NetBeans.
- Run the project and it will automatically open the application in web browser.
- Fill the personal im=nformation form and click on Submit Profile button.
- Users will be shown their infromation.
